Lucide icons (lucide-static 1.52.0, ISC licence), outline. These are the 33 icons DienstPilot uses, no more; the Iconography section of the brand book says what each one means and where it appears. The files keep Lucide's `stroke="currentColor"`. Shown through `<img>` they render black, so in product code use `lucide-react` / `lucide-react-native` (or `DienstPilot.icon`) with `strokeWidth={1.75} absoluteStrokeWidth`, coloured by the surrounding text token (`ink`, `ink-muted`, `pencil`, `alert`, `env`, `action`). Only `star` may be filled (`fill="currentColor"`), and only when a wish is marked important.
