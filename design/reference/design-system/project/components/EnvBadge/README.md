The environment badge, "Demo-Umgebung, synthetische Daten" / "Demo environment, synthetic data", required on every screen of the demo.

**Consumer provides:** `lang`, optional `bar: true` for the full-width strip at the top of the mobile app.

**Rules:** an ochre (`env`, `env-wash`) border and text with the Lucide `flask-conical` icon (16px): deliberately unlike any shift colour, and unlike `alert`, because demo data is not an error. On the dashboard it sits in the top bar, right-aligned. On mobile it is a strip under the status bar. It is never dismissible. In screenshots it stays visible.
