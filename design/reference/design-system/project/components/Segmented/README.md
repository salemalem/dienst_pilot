A small set of mutually exclusive options shown together: language, theme, view (Monat/Liste).

**Consumer provides:** `options` (`[{ value, label }]`), `value`, `label` (accessible group name), optional `name`, `onChange(value)`.

**Rules:** two to four options with short labels. The selected segment is an `action` fill with `on-action` text: the ballpoint blue of a human choice. Implemented as a radio group, so arrow keys move the selection. The theme control offers "Automatisch (20–7 Uhr dunkel)" as its default.
